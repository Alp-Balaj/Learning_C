# Learning_C

A personal repository for learning the C programming language from the ground up.

## About

This repo collects small C programs written while working through the fundamentals of C — input/output, arithmetic, control flow, functions, arrays, and external variables — along with solutions to practice exercises such as character counting, word counting, histograms, and tab replacement (`detab`).

## Structure

- `Chapter_1/` — introductory programs covering the basics of the language
- `Chapter_1/Exercises/` — exercise solutions building on those basics

## Building

Each file is a standalone program. Compile any of them with a C compiler, for example:

```sh
gcc Chapter_1/character_counting.c -o character_counting
./character_counting
```
